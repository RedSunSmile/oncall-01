## 비상근무 미션
# 입력
- [ ] 비상근무 월과 시작요일 만들기
- [ ] 평일 비상근무 순번 사원 닉네임 입력
- [ ] 휴일 비상근무 순번 사원 닉네임 입력
- [ ] 닉네임 중복 불가
- [ ] 닉네임 최대 5자
- [ ] 근무자 최소 5명, 최대 35명

# 달력
-[ ] 월마다 마지막 날(2월 28일, 4,6,9,11월 30일, 나머지 31일)
-[ ] 법정공휴일 (1/1, 3/1, 5/5, 6/6, 8/15, 10/3, 10/9, 12/25)
-[ ] 휴일은 토, 일, 법정공휴일
-[ ] 시작 요일부터 날짜마다 요일 이어 붙이기

# 배정                                                                                           
-[ ] 평일은 평일 순번, 휴일은 휴일 순번. 끝까지 가면 처음부터                                        
-[ ] 연속 근무면 다음 근무자와 바꾸기, 앞 날짜부터   
-[ ] 법정공휴일 수요일 수아비상근무, 다음날 평일 수아인경우
- ex) 평일 순번: 준팍,도밥,수아,루루,글로,솔로스타,우코,슬링키,참새,도리,고니
- ex)휴일 순번: 수아,루루,글로,솔로스타,우코,슬링키,참새,도리,준팍,도밥,고니
- 예시: 준팍(월요일),도밥(화요일),수아(수요일/휴일),루루(목요일),수아(금요일),루루(토요일),글로(일요일/휴일)

# 입력 검증
- [ ] 월 1~12, 요일 일~토, 형식 5,월
- [ ] 월/요일이 틀리면 -> 월/요일부터 다시
- [ ] 순번이 틀리면 -> 평일 순번부터 다시

# 출력
- [ ] 날짜마다 한 줄씩 출력 (형식:5월 1일 월 준팍)
- [ ] 평일이면서 법정 공휴일의 경우에만 요일 뒤에(휴일)표기
- ex) 5월 5일 금(휴일) 루루
- [ ] 올바르지 않을경우 [ERROR] 시작하는 에러 메시지 출력
- ex)[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.
- [ ] 비상근무표 출력을 완료하면 프로그램 종료
