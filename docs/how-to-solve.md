Worker first=queue.pollFirst();로 앞의 첫번째를 지웁니다.
if(!first.takeName().equals(yesterday))
queue.addLast(first); 로 어제 근무한 이름과 같지않다면 추가하면서 순서를 만듭니다.

Worker second=queue.pollFirst();
두번째로 그다음 자리를 지워주어 비워둡니다.

queue.addLast(second);로 두번째를 순서를 바꿔줍니다
